# 📝 Todo List

A simple todo list app with HTML, CSS, and JavaScript.

## Features
- Add and delete tasks
- Mark tasks as completed
- Filter tasks (all/completed/uncompleted)
- Save tasks in localStorage

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla)
